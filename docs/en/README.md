# The docs, in English

The part of [`docs/`](../README.md) that exists in English. Nothing here is
needed to take the course —the course is the slides and `code/`— but each one
solves something concrete.

| | |
|---|---|
| [`setup.md`](setup.md) | **How to get the course running.** The four roads —Codespaces, Docker, Verilator from source, WSL 2— plus seeds, waveforms and what the CI runs. The shortcut is `make doctor`, which says what is missing and which command installs it |
| [`uvm-interview.md`](uvm-interview.md) | The questions asked in a verification interview, with the short answer and a link to the section and to the example that runs |
| [`for-teachers.md`](for-teachers.md) | The 15-week map, what can be cut and what each cut costs, the two midterms, and how to mark the capstone in stages |
| [`exam-bank.md`](exam-bank.md) | Every review question of the course together, with the answer. **Generated from `slides/`** |
| [`silent-traps.md`](silent-traps.md) | The traps that raise no error: it compiles, it runs, it passes, and it verified nothing. Day 7 appendix. **Generated from `slides/`** |
| [`verification-plan.md`](verification-plan.md) | The five columns, the VTALU plan filled in row by row, and the empty template for the capstone. It is what gets handed in with the capstone, so it travels with the student |
| [`uvm-cheatsheet.pdf`](uvm-cheatsheet.pdf) | **The one-page cheat sheet**, A4, to print: the base class hierarchy, the nine phases, the driver handshake and the seven debug knobs. It comes out of [`res/en/machete.html`](../../res/en/machete.html) with `make machete`, which builds the Spanish one too |
| [`verilator.md`](verilator.md) | **The matrix.** Which example runs on which version of Verilator, what fails and why. The first thing to look at when something does not compile. Its Spanish source is generated by `make matrix`, and it **expires**: it holds for the version and date at the top |

The rest of `docs/` is still in Spanish, and the pages that link to it say so:
the SystemVerilog primer for whoever comes from VHDL, the page on what changes
when your job uses Questa, the Docker notes, how to edit the course, and the two
long background pieces on clocking blocks and on how this differs from the *UVM
Primer*. The full index is [`docs/README.md`](../README.md).

`exam-bank.md` and `silent-traps.md` are generated: the fix goes **in the
slide**, and `npm run check` fails if they are stale. The other five are
translations sealed against their Spanish source by `tools/lint-i18n.mjs` — if
the Spanish moves and the English does not, the build says so. `verilator.md` is
the special case: its Spanish source is itself regenerated whole by `make
matrix`, so every change of Verilator version makes the seal ask for the
translation to be revisited.
